# Kala Studio implementation wave

User requested a standalone Windows/Linux mechanical engineering app, CAD/analysis interoperability, live 3D preview, provider choice, and OpenCode implementation under ChatGPT review.

Model: opencode-go/minimax-m3 (available; existing OpenCode Console account). Three concurrent workers. No commits, pushes, deployment, credential reading, or edits to existing dirty FreeCAD/construction work.

## Shared contract

New `kala_agent.studio.server:create_studio_app` and `python -m kala_agent.studio --host 127.0.0.1 --port 8765` serve `/api/studio/*` and packaged `studio/dist` UI, separate from unchanged hardened core API. GET `/api/studio/health` returns `{status:"ok"}`. GET `/api/studio/integrations` returns `{integrations:[{id,name,category,platforms,status,capabilities,notes}]}`. GET `/api/studio/providers` returns `{providers:[{id,name,configured,notes}]}`. POST `/api/studio/chat` accepts `{provider,model,prompt,allow_remote}` and returns `{text}`. POST `/api/studio/preview` accepts `{kind:"box"|"cylinder"|"sphere",parameters:{...}}`, returns `{positions:[number],normals:[number],indices:[number],bounds:{...},engine:string,warnings:[string]}` with genuine server mesh, dimensions millimeters. POST `/api/studio/export` same body plus `{format:"stl"|"step"}`, returns downloadable file. POST `/api/studio/handoff` accepts `{integration_id,kind,parameters,format}` returns downloadable neutral artifact or honest unsupported error, never claims native connection. All writes require `Authorization: Bearer <KALA_STUDIO_TOKEN>`; desktop shell generates random token in parent process and supplies it ONLY through narrow preload IPC. Browser fallback requires manual token entry. Same-origin browser access only. No wildcard CORS, no arbitrary subprocess or file paths. No API key stored in frontend or committed.

Backend owns `src/kala_agent/studio/**`, `tests/unit/test_studio*.py`, `tests/security/test_studio*.py`. UI owns `studio/**` including lockfile. Delivery owns root `pyproject.toml`, `README.md`, `docs/studio*.md`, `packaging/**`, `.github/workflows/studio*.yml`, root `.gitignore`. Reports owned per cell. No overlapping ownership.

Acceptance: baseline preserved, existing tests pass; new routes reject unauthorized/cross-origin/oversized requests; geometry validation finite positive bounded and mesh export works; desktop renderer has no Node access, secrets, or arbitrary IPC; frontend builds; launch/install documentation and Windows/Linux build configurations honest about untested native packaging. Native vendor execution gated/unimplemented unless testable; no invented market-share ranking. Analysis target set ANSYS, Abaqus, COMSOL, Simcenter Nastran, Altair OptiStruct as representative not ranked top-five.
