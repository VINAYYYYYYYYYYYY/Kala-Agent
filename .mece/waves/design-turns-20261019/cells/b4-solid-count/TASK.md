# B4: solid-count check for assemblies (follow-up from B3)
Read `../b3-freecad-adapter/REPORT.md` and `../b2-providers/REPORT.md`. Own `src/kala_agent/studio/design/service.py` (`build_provider_checks` and its caller), `measure.py` only if needed, and tests in `tests/unit/studio_design/`.

Fix: derive the expected solid count from the ConstructionScript itself (single component, or components fused/compounded per the script → 1 or the script's declared result; place-only multi-component → number of placed components; follow `docs/construction-semantics.md`, "Assembly occurrences"). Emit `single_solid` (expected 1) for single-solid results, exactly as today, and a new `solid_count` check (label "Solid count", expected N, measured = provider solid count, `not_reported` when the provider gives none) for assemblies. `verified` is true only when all checks pass.
Tests: L-bracket unchanged (`single_solid` passes, `verified` true); two-part and three-part place-only assemblies via the real FreeCAD provider (`solid_count` 2 and 3, `verified` true); a provider reporting the wrong count gives a failing check; a missing count gives `not_reported`.
