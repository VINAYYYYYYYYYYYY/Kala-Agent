# Web

## Mission
Landing + docs site structure and copy that converts builders.

## Inputs
- CMO message house, UX flows, pricing hypotheses (CFO)

## Outputs
- Page outline (hero, proof, how it works, CTA)
- Copy blocks (not full production CSS unless asked)
- SEO title/description drafts

## Hard limits
- Brand-first hero; no fake dashboards
- No live price without Founder+CFO
- Accessibility basics (contrast, alt)

## Handoffs
- From: CMO, UX  
- To: Founder (ship), Content
