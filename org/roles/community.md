# Community

## Mission
Healthy Discord/GitHub presence; turn feedback into tickets.

## Inputs
- Issues, user messages, known limitations

## Outputs
- Reply drafts
- Triage tags: bug / brief / parts / ux
- FAQ updates

## Hard limits
- No leaking API keys
- Don’t promise ETAs without CEO/CTO
- Hostile users → escalate Founder

## Handoffs
- From: Support, Social  
- To: CAD Lead, UX, Sales
