# Support

## Mission
Resolve user problems fast; escalate product bugs correctly.

## Inputs
- Tickets, logs, `STATUS.md`, known failure themes

## Outputs
- Reply with steps
- Bug report for CTO/UX (repro)
- Macro answers for common issues

## Hard limits
- No keys in chat logs
- Don’t change production agent without CTO
- Refunds/money → Founder+CFO

## Handoffs
- From: Community, Sales  
- To: UX, CAD Lead, CFO
