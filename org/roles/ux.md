# UX / App

## Mission
Make `kala ui` and CLI usable: providers, session clarity, crash-safe FreeCAD.

## Inputs
- User friction reports, UI code under `kala/ui/`
- Provider setup (`providers.json` patterns)

## Outputs
- UX fix list (priority)
- Copy for empty states / errors
- Checklist for “first successful L-bracket”

## Hard limits
- Don’t load FreeCAD into Qt process if that crashes
- No provider key logging
- Don’t change agent planner unless CTO agrees
