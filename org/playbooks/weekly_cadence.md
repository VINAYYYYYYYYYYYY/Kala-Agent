# Weekly operating cadence

## Mon — Plan
1. Orchestrator asks CEO for 3 priorities
2. CFO pulse (burn + throttle?)
3. Update `org/STATUS.md`

## Daily — Build
1. Eval Ops: batch / overnight health
2. Design QA: sample new runs
3. CAD Lead/CTO: patch from `rectify_queue.md`
4. Re-run failed ids only

## Wed — Story
1. Design QA picks 3 demos
2. Content + Social draft
3. Founder approve/publish

## Fri — Review
1. CEO: keep/kill priorities
2. CFO: cost per pass
3. Orchestrator: write STATUS wins/blockers
